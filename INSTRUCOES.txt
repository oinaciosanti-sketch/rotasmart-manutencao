COMO APLICAR:
1. Faca backup do GitHub e do RotaSmart.
2. No GitHub, escolha Code > Download ZIP e extraia uma copia ATUAL do projeto completo.
3. Copie os arquivos deste pacote (aplicar_atualizacao.py e APLICAR_V83_WINDOWS.bat) para a RAIZ dessa copia, onde existe a pasta app.
4. Execute APLICAR_V83_WINDOWS.bat. Precisa ter Python 3 instalado.
5. Verifique a mensagem 'SUCESSO'. O arquivo anterior vira TechnicalReport.tsx.bak-before-v83 (nao envie o .bak ao GitHub).
6. No GitHub, substitua SOMENTE app/components/TechnicalReport.tsx pelo arquivo atualizado dessa copia.
7. Faca commit e aguarde o deploy Ready na Vercel. Abra um chamado e teste o botao e o fundo.

ATENCAO: Nao carregue os arquivos na raiz do GitHub. Nao envie o script nem o backup .bak. O ZIP e um atualizador, nao e o projeto completo.
Se a estrutura do projeto estiver diferente, o script interrompe antes de gravar.
