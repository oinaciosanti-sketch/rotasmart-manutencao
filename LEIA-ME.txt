ROTASMART — ATENDIMENTO TÉCNICO NO CHAMADO (MVP DEMONSTRATIVO)

INSTALAÇÃO NO GITHUB
1. Faça backup do repositório antes da atualização.
2. Extraia este ZIP no computador.
3. No GitHub, em Add file > Upload files, envie os TRÊS itens com suas pastas:
   - package.json (substituir o original)
   - app/components/TechnicalReport.tsx (novo arquivo)
   - scripts/apply-technical-report.cjs (novo arquivo)
   ATENÇÃO: respeite a estrutura das pastas. É mais fácil usar github.dev (tecla '.')
   para copiar os arquivos para as pastas correspondentes, se o upload web
   não preservar os diretórios.
4. Faça Commit changes. A Vercel executará o script antes de next build.
5. Se Build Command estiver fixado em Vercel Settings, deixe "pnpm build".
6. Após o deploy, abra um chamado cadastrado. Clique ATEND. TÉCNICO.
   No portal do técnico, abra o mesmo chamado e use o botão correspondente.

O QUE FUNCIONA
- Botão ATEND. TÉCNICO cinza quando não atendido, verde com relatório salvo
  ou status de atendimento técnico atendido/concluído.
- Descrição do serviço, materiais/peças, até 5 fotos compactadas.
- Horários e demais informações do chamado preenchidos automaticamente.
- Visualização do analista em modo leitura, lápis para edição.
- Geração de relatório formatado por impressão do navegador (Salvar como PDF).
- Número de chamado somente leitura após cadastrar.

LIMITAÇÃO IMPORTANTE
Esta entrega é um MVP para a instalação atualmente em MODO LOCAL.
Os registros e fotos de ATEND. TÉCNICO são armazenados no localStorage
DO NAVEGADOR QUE PREENCHEU: NÃO SÃO SINCRONIZADOS ENTRE CELULARES E PCs.
Por isso, NÃO atende ainda ao fluxo real de um técnico salvar no celular
para o analista visualizar imediatamente em outro dispositivo.
Para uso corporativo, integrar um banco de dados central e armazenamento
protegido de fotos com políticas de acesso, trilha de auditoria e backups.
Não utilize dados internos em uma DEMO pública sem verificar as fontes no código.

COMO A ATUALIZAÇÃO É APLICADA
A Vercel executa "node scripts/apply-technical-report.cjs && next build".
O script insere o componente no arquivo de edição de chamado e no portal
sem você precisar editar manualmente os 126 KB do app/page.tsx.
O script é idempotente: executar novamente não cria o componente duplicado.
Se você alterar profundamente os formulários no futuro, talvez seja preciso
adaptar os pontos de integração.
