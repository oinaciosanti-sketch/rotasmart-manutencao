ROTASMART CONTROL — VERSION 8.5

ESTA ATUALIZAÇÃO É LOCAL. NÃO ATIVA SINCRONIZAÇÃO, NÃO CONFIGURA SUPABASE E NÃO MUDA OS DADOS EXISTENTES.

INSTALAÇÃO PELO GITHUB — SEM SCRIPTS:
1. Abra o ZIP e a pasta app.
2. No seu repositório GitHub, abra app/page.tsx. Substitua o conteúdo pelo app/page.tsx deste ZIP e faça o commit.
3. No GitHub, abra app/components/TechnicianPortal.tsx. Substitua o conteúdo pelo arquivo correspondente deste ZIP e faça o commit.
4. No GitHub, entre em app/components e crie um arquivo chamado MobileAnalystPanel.tsx. Cole TODO o conteúdo do arquivo de mesmo nome deste ZIP e faça o commit.
5. Espere a Vercel concluir (Ready) e atualize a página (Ctrl+Shift+R).
