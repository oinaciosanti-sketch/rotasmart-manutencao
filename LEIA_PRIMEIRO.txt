PASSO A PASSO (Windows):
1. No GitHub do RotaSmart, clique em Code > Download ZIP. Extraia o projeto atual.
2. Extraia este pacote V8.3 em uma pasta a parte.
3. No seu computador, execute o Prompt de Comando na pasta do atualizador e digite:
   py -3 APLICAR_VERSION_8_3.py "C:\CAMINHO\DA\PASTA\DO\REPOSITORIO"
   (Substitua pelo caminho real da pasta do projeto extraido; Python 3 necessario.)
   Alternativamente, arraste a pasta do projeto para o .BAT.
4. Se aparecer SUCESSO, abra o arquivo do projeto app/page.tsx e procure por VERSION 8.3.
   Abra app/components/TechnicalReport.tsx e procure por rs-technical-report-v83.
   Se os DOIS marcadores estiverem presentes, a atualizacao foi aplicada ao projeto local.
5. GitHub: edite/substitua SOMENTE estes caminhos:
   app/page.tsx
   app/components/TechnicalReport.tsx
   NAO crie arquivos na raiz do GitHub. Nao envie backups nem script.
6. Confirme os commits, aguarde Ready na Vercel, e atualize com Ctrl + Shift + R.
7. Na barra lateral, logo abaixo de RotaSmart, deve aparecer VERSION 8.3.
   Abra um chamado: botao ATEND. TECNICO no alto, painel aberto em azul-claro.

Se o sistema nao mostrar a versao, o GitHub nao recebeu o app/page.tsx atualizado ou a Vercel ainda nao publicou o commit.
